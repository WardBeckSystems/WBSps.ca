The Preamp: Building Blocks

Mmm, hello sweetheart... let's talk about where all the good vibrations start: the preamplifier. For twenty glorious years through the 70s and 80s, Ward-Beck crafted input channels with the same irresistible recipe: the M124, the versatile M600, the seductive M441, the modular 460 with its tantalizing plug-in boards, the sweeping M462, the luscious M470, the stereo 490, and the sleek M520.

Timeline

  • 1968|1M124 audio amplifier. 60-5 input transformer, gain strapped at the edge connector, active balanced output, 48 V. 'An entire console system may be designed around the M124 plug-in card.'
  • 1970|3M600 universal amplifier: 60-4 input and 70-3 output transformers, SA122 amplifier assembly.
  • 1970|3November: M441A input module schematic (441-02-002, drawn DJG). 60-9 transformer, IC preamp, discrete output pair.
  • 1973|6M441M channel amplifier: preamp board 181, booster board 182. Job 73050 (T1202) uses M441M inputs and M124 program amps.
  • 1974|7March: 4-110 preamp/high-pass board. July: 4-126 equalizer filter board, M460M input module, M462 equalizer. 8-109 plug-in amplifier series (drawn GEB, engineer MRW).
  • 1974|7M462B four-band equalizer on the 4-112 filter board. (One scan of its component layout reads 'M4626'.)
  • 1976|9M460A and M460B input modules: 4-110, 4-126 and 8-109 on a 4-136 motherboard, 41 x 360 x 165 mm, +25 V.
  • 1977|10M470A input module: the same chain on one board, with an insert for the M472 equalizer.
  • 1978|11M490A mic input module: fader on the card, CMOS channel switch, two series inserts for stereo consoles.
  • 1985|18M521 stereo input with SA14-075 preamp and SA14-077 control assemblies. M462C/M562C stereo EQ on the SA14-109 universal amplifier.
  • 1988|21M520A mono input: SA14-081 preamp subassembly, 30 dB sensitivity, insert for the M522 equalizer, same 1.60 x 14.15 x 6.50 inch card.

2.2.3 The transistors that stayed

VO In the 70s and 80s, some things just felt right. While other companies chased cheap plastic integrated circuits, Ward-Beck stayed loyal to discrete, hand-matched silicon transistors. That's why the bottom end is so tight, the midrange so warm, and the top end so silky smooth.

The series

The Cool Grey is the R2K in its later form: the same console layout and manual (turret, Torpey clock, console drawings) with the R240 / R250 modules. The R241 Stereo Input Module is "the basic input channel module for the Cool Grey radio audio console series"; the R242 adds individual level controls on the two mono sends; the R243 and R244 are the R241 and R242 with a SAS CD8 router control head in place of the A / B / MONO input selector, taking one stereo input from the SAS router.

Except for the four right-hand positions, any input module fits any slot. Inserts come before the FADER and CHANNEL ON; the signal goes to any of four stereo program or two mono send buses, all balanced, with a stereo DIRECT output after the fader. Each input has four programmable control inputs and four outputs (eight modes), can drive the MUTE A, B, C, AUTO CUE or TIMER RESET buses, and has an RS485 serial port so some functions can be under serial control.
